Optionaler lokaler Sammelordner fuer manuelle Beta-Release-Pruefung.

Erst nach erfolgreichem PC-Test und ausdruecklicher Freigabe darf eine Kopie
von ArenaBridge.exe hier kurz abgelegt werden. Das ist weder Git-Commit-Ort
noch der oeffentliche Download-Ort. Fuer alle Nutzer wird nur die normale
ArenaBridge.exe als Asset an einen GitHub-Release angehaengt.

Niemals ArenaBridge-Diagnose.exe oder Diagnose-BAT veroeffentlichen. Inhalte
dieses Ordners werden von Git ignoriert.
