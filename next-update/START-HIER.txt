ARENA ROBLOX BRIDGE — START HIER
================================

NUR BAUEN UND TESTEN? DANN GENAU DIESE SCHRITTE:

1. Öffne den Ordner next-update.
2. Doppelklicke Build-EXE.bat. Das ist der einzige normale Startknopf.
3. Warte auf BUILD ERFOLGREICH. Die BAT zeigt dir den vollständigen Pfad.
4. Die zu startende Beta liegt anschließend hier:

       user-builds\beta\ArenaBridge.exe

   Starte diese Datei per Doppelklick. Schließe vorher alle älteren
   ArenaBridge-Fenster.
5. Wenn kein Fenster erscheint: andere Bridge-Fenster schließen und dann
   ausführen:

       user-builds\beta\Start-Diagnostic.bat

   Lass das Diagnose-Konsolenfenster offen. Die wichtigste Startdatei ist:

       %LOCALAPPDATA%\START-CHECK.txt

EIGENES LOGO FUER DIE EXE (OPTIONAL):

Kopiere dein eigenes Windows-Icon als ArenaBridge.custom.ico hierhin:

       app\assets\ArenaBridge.custom.ico

Beim nächsten Build wird es automatisch verwendet. Nur eine gültige .ico-Datei
funktioniert direkt (PNG/JPG vorher umwandeln). Lösche ArenaBridge.custom.ico,
um wieder das Standard-Logo zu verwenden. Deine eigene Icon-Datei wird nicht in
Git aufgenommen.

WICHTIG:

- Nicht builder\Build-EXE.ps1 und nicht den Updater starten.
- Zum Bauen brauchst du 64-Bit-Windows, Windows PowerShell 5.1 und beim ersten
  Build eine Internetverbindung für ps2exe. Keine Administratorrechte nötig.
- Der Build lädt nichts hoch. Hier in der Sandbox wurde keine Windows-EXE
  gebaut.
- Die alte Update-Struktur im Hauptordner bleibt unangetastet. Der neue
  Updater in update-system ist nur vorbereitet und noch nicht integriert; seine
  Channel-Manifeste stehen auf enabled: false.
- Keine EXE, Diagnose-Datei oder persönliche ICO-Datei in Git committen.
